Οδηγίες ρύθμισης του Input Gate

Το gate ελέγχει μόνο τη στιγμιαία ένταση του μικροφώνου. Η ομιλία περνά όταν το Current Input είναι πάνω από 100%.

Προτεινόμενο σημείο εκκίνησης:
Trigger Frames 7 · Hold 300 ms · Polling 25 ms · Look-ahead 250 ms

1. Consecutive Trigger Frames

Καθορίζει πόσες συνεχόμενες μετρήσεις πρέπει να είναι πάνω από 100% πριν ανοίξει το gate.

2. Hold After Input Drops

Καθορίζει πόσο χρόνο μένει ανοικτό το gate αφού το Current Input πέσει στο 100% ή χαμηλότερα.

3. Polling Interval

Καθορίζει κάθε πόσα milliseconds γίνεται νέα μέτρηση του Current Input.

4. Look-ahead Delay

Καθυστερεί εσωτερικά τον ήχο ώστε να μη χάνεται η αρχή της πρώτης λέξης όσο το gate επιβεβαιώνει ότι το input ξεπέρασε το 100%.

Σημαντικό: Δεν γίνεται βαθμονόμηση αίθουσας και δεν υπολογίζεται Room Level ή Difference.
